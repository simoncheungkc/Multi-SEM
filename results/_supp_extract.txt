[4|] Section S1: Mathematical Proofs and Spectral Analysis
[5|] S1.1 Proof of the Sufficient l1 Norm Bound for Invertibility and Spectral Stability
[6|] Let {A_1, A_2, ..., A_k} denote a set of k row-standardized n x n adjacency matrices defined on a common vertex set V, where |V| = n. For every entity i that is not an isolate, sum_{j=1}^n A_{s, ij} = 1 with A_{s, ij} >= 0; for isolated nodes, A_{s, ij} = 0 for all j. The induced matrix l_infinity norm (maximum absolute row sum) satisfies:
[7|] ||A_s||_infinity = max_{1 <= i <= n} sum_{j=1}^n |A_{s, ij}| <= 1,   forall s in {1, ..., k}    (S1.1)
[8|] Let rho(B) = max {|mu| : mu in sigma(B)} denote the spectral radius of an arbitrary square matrix B, where sigma(B) denotes its spectrum. Because the spectral radius of any matrix is bounded above by any induced matrix norm, we have rho(A_s) <= ||A_s||_infinity <= 1.
[9|] In the Multiplex Spatial Error Model (Multi-SEM), the spatial filter operator is defined as:
[10|] V(lambda) = I_n - sum_{s=1}^k lambda_s A_s    (S1.2)
[11|] The operator V(lambda) is invertible if and only if 0 is not an eigenvalue of V(lambda), which is equivalent to stating that 1 is not an eigenvalue of the composite matrix sum_{s=1}^k lambda_s A_s. A sufficient condition ensuring that V(lambda) is non-singular and that the spatial multiplier Neumann series expands as:
[12|] K(lambda) = V(lambda)^(-1) = sum_{m=0}^infinity (sum_{s=1}^k lambda_s A_s)^m    (S1.3)
[13|] is that the spectral radius satisfies rho(sum_{s=1}^k lambda_s A_s) < 1. Applying the triangle inequality and the submultiplicativity of induced matrix norms yields:
[14|] rho(sum_{s=1}^k lambda_s A_s) <= ||sum_{s=1}^k lambda_s A_s||_infinity <= sum_{s=1}^k |lambda_s| ||A_s||_infinity <= sum_{s=1}^k |lambda_s|    (S1.4)
[15|] Therefore, imposing the l1 norm parameter bound:
[16|] sum_{s=1}^k |lambda_s| < 1    (S1.5)
[17|] strictly guarantees that rho(sum_{s=1}^k lambda_s A_s) < 1. This condition ensures that V(lambda) is non-singular and that the disturbance covariance matrix Omega(lambda, sigma^2) = sigma^2 (V'V)^(-1) is positive-definite across any collection of row-stochastic networks. This formalizes the parameter space D_{l1} implemented in the prior configuration of Table 1.
[18|] S1.2 Finite-Sample Moments of the Residual Moran's I Statistic (Cliff–Ord Derivation)
[19|] Under the null hypothesis of no spatial/network autocorrelation across all candidate networks (H_0: lambda_1 = ... = lambda_k = 0), the true model is Y = X beta + epsilon with epsilon ~ N(0, sigma^2 I_n). Fitting by Ordinary Least Squares (OLS) yields the residual projection matrix:
[20|] M = I_n - X (X'X)^(-1) X'    (S1.6)
[21|] which is symmetric (M = M') and idempotent (M^2 = M) with rank d = tr(M) = n - p - 1. The OLS residual vector is e = M Y = M epsilon. For candidate network A_s, the residual Moran's I statistic is:
[22|] I_s = (e' A_s e) / (e' e) = (epsilon' M A_s M epsilon) / (epsilon' M epsilon) = (epsilon' P_s epsilon) / (epsilon' M epsilon)    (S1.7)
[23|] where P_s = 0.5 * M (A_s + A_s') M is a real symmetric matrix. Because epsilon is spherical Gaussian, by Pitman's theorem the ratio of quadratic forms I_s is statistically independent of its denominator epsilon' M epsilon = e'e. Taking expectations on both sides of epsilon' P_s epsilon = I_s (epsilon' M epsilon):
[24|] E[epsilon' P_s epsilon] = E[I_s] * E[epsilon' M epsilon]    (S1.8)
[25|] Using standard quadratic form expectation identities for Gaussian vectors (E[epsilon' C epsilon] = sigma^2 tr(C)):
[26|] E[epsilon' P_s epsilon] = sigma^2 tr(P_s) = sigma^2 tr(M A_s M) = sigma^2 tr(M A_s)    (S1.9)
[27|] E[epsilon' M epsilon] = sigma^2 tr(M) = sigma^2 (n - p - 1)    (S1.10)
[28|] Substituting Equations (S1.9) and (S1.10) into Equation (S1.8) yields the analytical conditional expectation:
[29|] E[I_s | X] = tr(M A_s) / (n - p - 1)    (S1.11)
[30|] To compute the conditional variance Var(I_s | X) = E[I_s^2 | X] - (E[I_s | X])^2, we evaluate the second moment via Pitman's theorem:
[31|] E[(epsilon' P_s epsilon)^2] = E[I_s^2] * E[(epsilon' M epsilon)^2]    (S1.12)
[32|] For any symmetric matrix C and epsilon ~ N(0, sigma^2 I_n), E[(epsilon' C epsilon)^2] = sigma^4 [ 2 tr(C^2) + (tr(C))^2 ]. Applying this identity to P_s and M:
[33|] E[(epsilon' P_s epsilon)^2] = sigma^4 [ 2 tr(P_s^2) + (tr(P_s))^2 ]    (S1.13)
[34|] E[(epsilon' M epsilon)^2] = sigma^4 [ 2 tr(M^2) + (tr(M))^2 ] = sigma^4 d(d + 2)    (S1.14)
[35|] where d = n - p - 1. Noting that tr(P_s^2) = 0.5 * [ tr(M A_s M A_s') + tr((M A_s)^2) ] and tr(P_s) = tr(M A_s), substituting into Equation (S1.12) gives:
[36|] E[I_s^2 | X] = [ tr(M A_s M A_s') + tr((M A_s)^2) + (tr(M A_s))^2 ] / [ (n - p - 1)(n - p + 1) ]    (S1.15)
[37|] Subtracting (E[I_s | X])^2 yields the exact finite-sample variance expression:
[38|] Var(I_s | X) = [ tr(M A_s M A_s') + tr((M A_s)^2) + (tr(M A_s))^2 ] / [ (n - p - 1)(n - p + 1) ] - [ tr(M A_s) / (n - p - 1) ]^2    (S1.16)
[39|] S1.3 Asymptotic Normality of the Residual Moran Score
[40|] Under mild spatial regularity conditions (uniform boundedness of row and column sums of A_s and M, finite fourth moments of innovations, and full-rank design matrix X), the central limit theorem for linear-quadratic forms of Kelejian & Prucha (2001) applies to epsilon' P_s epsilon. Because (1/n) epsilon' M epsilon converges in probability to sigma^2, Slutsky's theorem establishes that the standardized score converges to a standard normal distribution:
[41|] Z_s = [ I_s - E[I_s | X] ] / sqrt( Var(I_s | X) ) ---> N(0, 1)   as n ---> infinity    (S1.17)
[42|] The two-sided p-value p_s = 2(1 - Phi(|Z_s|)) is continuous and uniformly distributed on [0, 1] under H_0.
[43|] S1.4 Precision-Based Dual Spatial Kriging Equivalence Proof
[44|] Partition the n entities into holdout test nodes S (n_* nodes) and observed training nodes T (n_t nodes). The disturbance vector u in R^n has covariance Omega = sigma^2 (V'V)^(-1) and precision Q = Omega^(-1) = (1/sigma^2) V'V. Partition Q conformably:
[45|] Q = [ Q_{*, *}   Q_{*, t} ;  Q_{t, *}   Q_{t, t} ]    (S1.18)
[46|] Let Omega = [ Omega_{*, *}   Omega_{*, t} ;  Omega_{t, *}   Omega_{t, t} ] denote the inverse of Q. By block matrix inversion:
[47|] [ Omega_{*, *}  Omega_{*, t} ; Omega_{t, *}  Omega_{t, t} ] * [ Q_{*, *}  Q_{*, t} ; Q_{t, *}  Q_{t, t} ] = [ I_{n_*}  0 ; 0  I_{n_t} ]    (S1.19)
[48|] Expanding the lower-left block yields:
[49|] Omega_{t, *} Q_{*, *} + Omega_{t, t} Q_{t, *} = 0   ===>   Omega_{t, t} Q_{t, *} = - Omega_{t, *} Q_{*, *}    (S1.20)
[50|] Multiplying Equation (S1.20) on the left by Omega_{t, t}^(-1) and on the right by Q_{*, *}^(-1) gives:
[51|] Q_{t, *} Q_{*, *}^(-1) = - Omega_{t, t}^(-1) Omega_{t, *}    (S1.21)
[52|] Taking the transpose (since Omega and Q are symmetric):
[53|] Omega_{*, t} Omega_{t, t}^(-1) = - Q_{*, *}^(-1) Q_{*, t}    (S1.22)
[54|] Similarly, by the Schur complement identity:
[55|] Omega_{*, *} - Omega_{*, t} Omega_{t, t}^(-1) Omega_{t, *} = Q_{*, *}^(-1)    (S1.23)
[56|] Substituting Equations (S1.22) and (S1.23) into the spatial BLUP kriging equation:
[57|] hat{Y}_* = X_* hat{beta} + Omega_{*, t} Omega_{t, t}^(-1) (Y_t - X_t hat{beta}) = X_* hat{beta} - Q_{*, *}^(-1) Q_{*, t} (Y_t - X_t hat{beta})    (S1.24)
[58|] This proves that the dual precision formulation is mathematically identical to covariance kriging while reducing the inversion dimension from n_t x n_t to n_* x n_*.
[59|] S1.5 Invariance of Block-Diagonal Affiliation Resolvents under Row-Normalization
[60|] Consider an unweighted affiliation network with M disjoint groups, where entities in group m form a fully connected clique of size n_m. The adjacency matrix A is block-diagonal: A = diag(C_1, ..., C_M), where C_m = (1/n_m) 1_{n_m} 1_{n_m}'. Computing matrix powers:
[61|] C_m^2 = (1/n_m^2) 1_{n_m} (1_{n_m}' 1_{n_m}) 1_{n_m}' = (n_m / n_m^2) 1_{n_m} 1_{n_m}' = C_m    (S1.25)
[62|] By induction, C_m^l = C_m for all integers l >= 1. The boosted resolvent matrix is GA = A(I_n - alpha A)^(-1) = sum_{l=1}^infinity alpha^(l-1) A^l. For each diagonal block C_m:
[63|] GC_m = sum_{l=1}^infinity alpha^(l-1) C_m^l = ( sum_{l=1}^infinity alpha^(l-1) ) C_m = [ 1 / (1 - alpha) ] C_m    (S1.26)
[64|] Because 1 / (1 - alpha) is a uniform positive scalar, row-standardizing GC_m yields:
[65|] [GC_m]_{row-norm} = [ (1 - alpha)^(-1) D_{C_m} ]^(-1) [ (1 - alpha)^(-1) C_m ] = D_{C_m}^(-1) C_m = C_m    (S1.27)
[66|] Thus, for any block-diagonal affiliation graph, the row-standardized resolvent is identical to the base matrix (GA_{row-norm} == A), introducing exact collinearity (r = 1.0) if entered simultaneously.
[67|] Section S2: Complete Bayesian Derivations and Algorithmic Specifications
[68|] S2.1 Derivation of Conditional Posteriors for beta and sigma^2
[69|] The Multi-SEM likelihood is:
[70|] p(Y | X, beta, sigma^2, lambda) = (2 pi sigma^2)^(-n/2) |V(lambda)| exp( - (1 / (2 sigma^2)) (Y - X beta)' V'V (Y - X beta) )    (S2.1)
[71|] Given conjugate priors beta ~ N(mu_0, Sigma_0) and sigma^2 ~ Inv-Gamma(alpha_0, gamma_0) from Table 1, the joint posterior distribution is:
[72|] p(beta, sigma^2, lambda | Y, X) propto |V(lambda)| (sigma^2)^(-(n/2 + alpha_0 + 1)) exp( - (1 / sigma^2) [ gamma_0 + 0.5 (Y - X beta)' V'V (Y - X beta) ] ) * exp( - 0.5 (beta - mu_0)' Sigma_0^(-1) (beta - mu_0) - 0.5 xi lambda'lambda ) I(sum |lambda_s| < 1)    (S2.2)
[73|] Conditioning on (sigma^2, lambda), define filtered outcome Y_tilde = V(lambda) Y and regressor X_tilde = V(lambda) X. Completing the square for beta:
[74|] beta | Y, X, sigma^2, lambda ~ N(mu_beta, Sigma_beta)    (S2.3)
[75|] Sigma_beta = [ Sigma_0^(-1) + (1 / sigma^2) X' V(lambda)' V(lambda) X ]^(-1)    (S2.4)
[76|] mu_beta = Sigma_beta [ Sigma_0^(-1) mu_0 + (1 / sigma^2) X' V(lambda)' V(lambda) Y ]    (S2.5)
[77|] Conditioning on (beta, lambda), Equation (S2.2) factors as a function of sigma^2, matching the Inverse-Gamma distribution:
[78|] sigma^2 | Y, X, beta, lambda ~ Inv-Gamma(alpha_0 + n/2,   gamma_0 + 0.5 (Y - X beta)' V'V (Y - X beta))    (S2.6)
[79|] S2.2 Metropolis-within-Gibbs Step for lambda on the l1 Unit Ball
[80|] Conditioning on (beta, sigma^2), let e = Y - X beta. The full conditional density for lambda is:
[81|] p(lambda | Y, X, beta, sigma^2) propto |V(lambda)| exp( - (1 / (2 sigma^2)) e' V(lambda)' V(lambda) e - 0.5 xi ||lambda||_2^2 ) I(sum_{s=1}^k |lambda_s| < 1)    (S2.7)
[82|] Given proposal candidate lambda* ~ N(lambda^(t-1), tau_t^2 Sigma_lambda):
[83|] 1. If sum_{s=1}^k |lambda_s*| >= 1, reject immediately: set alpha = 0 and lambda^(t) = lambda^(t-1).
[84|] 2. If sum_{s=1}^k |lambda_s*| < 1, evaluate acceptance probability:
[85|] alpha = min( 1,   exp[ Delta ln|V| - (Delta Q / (2 sigma^2)) - 0.5 xi ( ||lambda*||_2^2 - ||lambda^(t-1)||_2^2 ) ] )    (S2.8)
[86|] where Delta ln|V| = ln|V(lambda*)| - ln|V(lambda^(t-1))| and Delta Q = e' V(lambda*)' V(lambda*) e - e' V(lambda^(t-1))' V(lambda^(t-1)) e.
[87|] ALGORITHM S1
[88|] Algorithm S1: Adaptive Metropolis-within-Gibbs Sampler for Multi-SEM
[89|] -----------------------------------------------------------------------------------------
[90|] Input : Data Y in R^n, design X in R^{n x (p+1)}, row-stochastic networks {A_1, ..., A_k},
[91|]         iterations N_iter, burn-in N_burn, target acceptance alpha_star = 0.30.
[92|] Output: Retained posterior sample draws {beta^(t), (sigma^2)^(t), lambda^(t)} for t > N_burn.
[93|] 
[94|] 1. Initialize beta^(0) ~ N(mu_0, Sigma_0), (sigma^2)^(0) ~ Inv-Gamma(alpha_0, gamma_0),
[95|]    lambda^(0) = 0 in D_{ell_1}. Set proposal scale tau_0 = 2.38 / sqrt(k).
[96|] 2. For iteration t = 1, 2, ..., N_iter:
[97|]    a. Compute spatial filter V = I_n - sum_{s=1}^k lambda_s^(t-1) A_s.
[98|]    b. Sample beta^(t) from N(mu_beta, Sigma_beta) using Equations (S2.4) and (S2.5).
[99|]    c. Compute residual e = Y - X beta^(t).
[100|]    d. Sample (sigma^2)^(t) from Inv-Gamma(alpha_0 + n/2, gamma_sigma) using Equation (S2.6).
[101|]    e. Propose lambda* ~ N(lambda^(t-1), tau_{t-1}^2 I_k).
[102|]    f. If sum_{s=1}^k |lambda_s*| >= 1:
[103|]         lambda^(t) = lambda^(t-1)
[104|]       Else:
[105|]         Evaluate log|V(lambda*)| and log|V(lambda^(t-1))| via LU decomposition.
[106|]         Compute acceptance alpha from Equation (S2.8).
[107|]         Draw u ~ Uniform(0, 1).
[108|]         If u <= alpha: lambda^(t) = lambda*
[109|]         Else:          lambda^(t) = lambda^(t-1)
[110|]    g. If t <= N_burn (Adaptive scaling):
[111|]         log(tau_t) = log(tau_{t-1}) + t^{-0.5} * (alpha - alpha_star).
[112|] 3. Return post-burn-in draws across parallel chains.
